# 一麦管理工作台

> 一麦瑜伽 · 双店内部经营与服务执行平台
>
> **当前版本 v3.1.4** · 版本记录见 [CHANGELOG.md](CHANGELOG.md)

面向**超管 / 店长 / 老师 / 新媒体**四类角色的内部工作台：把客资承接、体验成交、会员维护、续费预警、任务审批放进一个闭环，AI 内容生成作为效率工具嵌入。

生产部署采用单域名单站点：Vue 构建产物位于 Laravel `public`，页面和 `/api` 共用同一 HTTPS 域名。

## 技术栈

| 层 | 选型 |

## 功能模块

```
一麦工作台
├── 工作台          四角色各自的数据仪表盘（KPI+趋势图+渠道对比+漏斗）
├── 会员管理        五清单引擎：待续课/出勤降低/VIP/预流失/待复活（口径：卓越店长训练营）
│                   ├ 会籍顾问独立列 + 筛选（未分配红标；按手机号匹配留资服务老师，全系统统一「会籍顾问」口径）
│                   └ 30天续费评估打分器（8维度，阈值可调）
├── 留资管理        新媒体录入→店长分配→会籍顾问跟进，全字段变更留痕
├── 客户经营池      超管全景视图（KeepYoga会员、卡项、签到数据聚合，会籍顾问匹配联动）
├── 任务中心        新建任务/认领执行/分配负责人/店长验收 全流程
├── 价格审批        发起审批→店长初审→超管终审→关联成交，未审批不能标记成交
├── 训练计划        AI生成草稿→老师确认→H5分享页（含对比照相册）
├── 谈单工具        门店资料/产品价目/教练/案例管理 + 免登录H5分享页
├── 营销工具        朋友圈/小红书文案生成（大模型API可配置，人工确认后发布）
├── KeepYoga同步    只读接入·实时计数·今日预约快照·会员卡/出勤多表同步（仅超管）
├── 操作留痕        全系统修改类操作审计，超管可溯源
├── 人员管理        开通新账号/停用启用/重置密码/角色与门店范围（仅超管）
└── 模型配置        大模型API接入管理，密钥存服务端数据库、多设备共用（仅超管）
```

## 快速开始

```bash
cd admin-web
pnpm install          # 需 Node ≥ 20.19，pnpm ≥ 8.8
pnpm dev              # http://localhost:3006
```

### 本地演示认证

生产环境必须使用 Laravel 后端认证。只有显式设置 `VITE_DEMO_PASSWORD` 时，本地前端模式才启用演示账号；演示账号和密码不得用于生产。

### KeepYoga 数据接入

生产和后端模式下，在服务器环境变量中配置，或登录后台后进入“KeepYoga同步 → 登录账号设置”：

```env
KY_PHONE=随心瑜登录手机号
KY_PASSWORD=随心瑜登录密码
```

配置后以超管登录 → KeepYoga同步 → 可获取双店实时计数、今日预约快照，并执行会员基础、卡项、团课/私教签到多表同步。

同步会把随心瑜的会员 `member_id` 与卡项、预约记录中的 `m_id` 对齐。会员管理使用最近三个完整自然月的“已签到”次数计算待续课、出勤降低、预流失等清单；过期、退卡、停卡不作为有效资产。

### AI 大模型配置

超管登录 → 模型配置 → 选择服务商 → 填入 API Key → 测试连接。
未配置时营销工具/训练计划自动降级为本地模板草稿。
