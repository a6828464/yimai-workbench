# 一麦管理工作台

> 一麦瑜伽 · 双店内部经营与服务执行平台

面向**超管 / 店长 / 老师 / 新媒体**四类角色的内部工作台：把客资承接、体验成交、会员维护、续费预警、任务审批放进一个闭环，AI 内容生成作为效率工具嵌入。

---

## 技术栈

| 层 | 选型 |
|----|------|
| 前端 | Vue 3.5 + TypeScript + Vite 7 + Element Plus + Tailwind CSS 4 |
| 状态 | Pinia（localStorage 持久化，演示期免后端） |
| 图表 | ECharts 6（art-design-pro 封装组件） |
| AI | OpenAI 兼容协议，支持 DeepSeek / 通义千问 / Kimi / GLM / 豆包 |
| 数据接入 | 随心瑜云 KeepYoga（只读，Vite 服务端代理） |
| 目标后端 | Laravel 12 模块化单体 + MySQL 8（阶段1替换本地Mock） |

## 功能模块

```
一麦工作台
├── 工作台          四角色各自的数据仪表盘（KPI+趋势图+渠道对比+漏斗）
├── 会员管理        五清单引擎：待续课/出勤降低/VIP/预流失/待复活（口径：卓越店长训练营）
│                   └ 30天续费评估打分器（8维度，阈值可调）
├── 留资管理        新媒体录入→店长分配→老师跟进，全字段变更留痕
├── 客户经营池      超管全景视图（按手机号聚合，KeepYoga全量导入）
├── 任务中心        任务分派/过程反馈/店长验收
├── 价格审批        特殊价格两级审批（店长初审→超管终审），未审批不能标记成交
├── 训练计划        AI生成草稿→老师确认→H5分享页（含对比照相册）
├── 谈单工具        门店资料/产品价目/教练/案例管理 + 免登录H5分享页
├── 营销工具        朋友圈/小红书文案生成（大模型API可配置，人工确认后发布）
├── KeepYoga同步    只读接入·实时计数·今日预约快照·全量导入（仅超管）
├── 操作留痕        全系统修改类操作审计，超管可溯源
├── 人员管理        账号与角色总览（仅超管）
└── 模型配置        大模型API接入管理（仅超管）
```

## 快速开始

```bash
cd admin-web
pnpm install          # 需 Node ≥ 20.19，pnpm ≥ 8.8
pnpm dev              # http://localhost:3006
```

### KeepYoga 数据接入（可选）

在项目根目录创建 `admin-web/.env.local`（已被 .gitignore 保护，不入库）：

```env
KY_PHONE=随心瑜登录手机号
KY_PASSWORD=随心瑜登录密码
```

配置后以超管登录 → KeepYoga同步 → 可获取双店实时计数、今日预约快照、全量导入会员。

### AI 大模型配置

超管登录 → 模型配置 → 选择服务商 → 填入 API Key → 测试连接。
未配置时营销工具/训练计划自动降级为本地模板草稿。

## 目录结构

```
一麦工作台/
├── admin-web/              # 管理后台应用（本仓库主体）
│   ├── src/api/            # 业务接口层（本地Mock，阶段1换Laravel）
│   ├── src/store/modules/  # Pinia：客资/会员/训练/谈单/AI配置
│   ├── src/views/yimai/    # 一麦业务页面
│   ├── src/views/sales-share/   # 谈单H5分享页（免登录）
│   ├── src/views/training-share/ # 训练计划H5分享页（免登录）
│   └── vite-plugins/keepyoga.ts # KeepYoga服务端代理（阶段1由Laravel替换）
├── sync.ps1                # 一键同步：提交+变更日志+推送GitHub
├── CHANGELOG.md            # 自动生成的更新日志
└── *.docx / *.md / *.xlsx  # 架构书、需求报告、业务数据
```

## 版本同步

```powershell
.\sync.ps1 -m "feat: 本次改动说明"   # 暂存→写CHANGELOG→提交→推送
```
