2. **徽标必须带 `type=member`**。不带时后端走「兼容路径」按全部客户算，会出现「徽标 4、点进去 3 行」。`listCounts()` 注释里明确写了这条历史坑。
3. **留资编辑只提交 diff**。`LeadController::update` 对 `source/orderPlatform` 是「改动才校验」，原样带回的历史值放行；少提交就不会把库里的历史枚举值改坏（`LeadController.php:83-95` 的整段警告）。
4. **编辑态用本地草稿传参**，因为后端没有 `GET /leads/{id}`（只有列表 `index`）。草稿键 `yimai-lead-draft`，取用即删。若将来加单条详情接口，应改为直取以支持多设备/多实例。
5. **不引 ECharts、不做表格**：详情页卡项/评估一律只读卡片，看板类仍留桌面（`03` §2.2 口径）。
