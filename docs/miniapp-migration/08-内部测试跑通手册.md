# 08 · 内部测试跑通手册（体验版）

> **目标**：绕开第三方、不经过审核、不点发布，让 1–3 个同事在真机上用起来。
> **范围**：只到「体验版」。审核、发布、微信授权登录都不在本次范围内。
> **前置事实**：小程序管理员在你手上，可自行控制后台。
> 编写日期：2026-11-04。技术验证部分均为本机实测，非文档推断。

---

## 0 先明确一件事：体验版不能靠「不校验域名」蒙过去

开发者工具里勾「不校验合法域名」只对**工具本身**生效。体验版跑在微信正式沙箱里，`wx.request` 一样强制校验 `request` 合法域名，没配就是 `url not in domain list`，页面直接白屏。

**所以第 2 步的域名配置是硬前提，不是可选项。**

---

## 1 解除第三方授权（本次的核心动作）

之前那套代码是第三方发布的，代码上传通道在第三方手里。不解绑，你点「上传」会没有权限入口。

### 操作路径

```
mp.weixin.qq.com 登录
  → 设置 → 第三方设置 → 授权管理
  → 找到对应第三方平台 → 解除授权
```

### 解绑后会发生什么

| 事项 | 结果 |
|---|---|
| 线上旧版本 | **保留，不会被下架**。旧版本代码已经存在微信侧，与授权无关 |
| 第三方发新版本 | ❌ 不能再发（这正是你要的） |
| 你自己上传代码 | ✅ 「开发管理」恢复上传权限 |
| 第三方提供的功能（地图/客服/插件等） | ⚠️ 若旧版本依赖第三方注入的能力，可能失效 |
| 小程序备案 | ❌ 不受影响（备案绑 AppID，与授权无关） |

### 关于你看到的「腾讯地图接入后台」

已经查过新代码：`src/` 与 `package.json` 中 **零第三方 SDK、零地图依赖**（无 `qqmap` / `TMap` / `amap` / `chooseLocation` / `plugin://`）。

结论：**解绑不会影响这套新代码**。腾讯地图那块是第三方平台的模块，只影响旧版本。

> ⚠️ 解绑前确认一句：线上旧版本现在有没有真实用户在用？如果有，解绑后旧版本虽然还在，但第三方不会再维护它。内部工具一般无所谓。

### 如果解绑后「上传」仍然没权限

两种情况：
1. 该第三方是**「第三方平台代开发」模式**（不是普通授权），需要在第三方控制台解除「代码管理权限」，或让对方在后台操作一次
2. 你的账号是管理员但没有被列为**「项目成员」**——去「成员管理 → 项目成员」把自己加上，权限选「开发者」

## 2 配置服务器域名（5 分钟，硬前提）

```
mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名
```

| 类型 | 填什么 | 是否必填 |
|---|---|---|
| request 合法域名 | `https://oa.nbyimai.com` | ✅ **必填** |
| uploadFile 合法域名 | 当前代码不用 | 暂不需要 |
| downloadFile 合法域名 | 当前代码不用 | 暂不需要 |
| socket 合法域名 | 当前代码不用 | 暂不需要 |

**填写规则**（填错会保存失败）：
- 只填域名，**不带路径**（不要 `https://oa.nbyimai.com/api`）
- **不带端口**
- 必须 HTTPS
- 必须已备案

### 这个域名的实测状态（2026-11-04 本机验证）

| 检查项 | 结果 |
|---|---|
| HTTPS 可达 | ✅ `/api/me` 返回 401（未登录的正常响应），耗时 0.58s |
| 证书主体 | ✅ `CN=oa.nbyimai.com` |
| 证书签发 | Let's Encrypt，**有效期至 2027-01-26** |
| TLS 1.2 | ✅ 可用 |
| TLS 1.1 | ✅ 已被服务器拒绝（比方案文档记录的「仍开着」更好） |
| 登录接口契约 | ✅ 错误凭据返回 422 + 「账号或密码错误」 |

> 域名生效约需几分钟，别填完立刻扫码，容易误判成代码问题。


产物在 `miniapp/dist/build/mp-weixin`（本次已实测构建通过）。

微信开发者工具 → 导入项目 → 选这个目录：

| 项 | 值 |
|---|---|
| AppID | `wx3a5379d124e2499c`（产物 `project.config.json` 已带，无需手填） |
| 项目名称 | 一麦工作台 |

- [ ] 打开小程序，落在登录页（不是白屏）
- [ ] 用现有 web 端账号密码能登录进去
- [ ] 工作台显示「早上好/下午好 + 姓名 + 门店」

- [ ] 「今日待办」有分组和条目，点动作能提交
- [ ] 「任务」列表有数据，能改状态
- [ ] 「审批」能同意/驳回（店长及以上账号）
- [ ] 「课后分析」「训练计划」能看到列表

| 场景 | 期望表现 |

## 7 这一版跑不通的，都不是 bug

| 现象 | 原因 | 什么时候解决 |
|---|---|---|
| 登录页没有「微信授权登录」按钮 | `VITE_WX_LOGIN_ENABLED=false`；且后端 `.env` **未配** `WECHAT_MINI_APPID/SECRET`（已核实） | 上线前 |
| 课后分析/训练计划只能看不能改 | M2 未做 | M2 |
| tabBar 只有文字没有图标 | `pages.json` 未配 `iconPath`（可选项） | 想要就加，不影响功能 |
| 首页数字卡少一两张 | 字段名按后端实际返回宽匹配，缺字段自动隐藏 | 内测后按真实返回校正 |

## 8 排错表

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| `url not in domain list` | 域名没配或配错 | 回第 2 步，注意不带路径 |
| 体验版白屏但调试模式正常 | 同上，调试模式绕过了校验 | 配域名，别依赖调试模式 |
| 上传按钮灰色/无权限 | 第三方未解绑，或自己不是项目成员 | 回第 1 步 |
| 登录一直提示网络异常 | 手机访问不到 `oa.nbyimai.com` | 手机浏览器打开 `https://oa.nbyimai.com` 验证 |
| 请求 403 | 账号角色不足（审批需店长+） | 换账号或找超管加角色 |
| 请求 422 且提示文案正确 | **正常**，是业务校验 | 不是 bug |
