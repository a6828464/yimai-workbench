## 3 权限矩阵（唯一事实来源：`src/utils/permission.ts`）

| 功能 | 允许角色 | 备注 |
|---|---|---|
| 今日待办 / 新客培养 / 留资管理 / 营销工具 / 我的全部 | ALL | 新媒体也可见 |
| 会员管理 / 任务中心 / 课后分析 | OPS | **不含 R_MEDIA** |
| 训练计划 | TEACHING | SUPER / MANAGER / TEACHER |
| 价格审批 / 谈单工具 | MGMT | SUPER / MANAGER（后端 `assertCanManageSales` 同口径） |
| 客户经营池 | SUPER | 后端 `/customers` 无角色门，靠前端 + 超管语义 |

规则：
1. 入口渲染一律走 `visibleFeatures(roles, area)`，禁止页面里手写 `roles.includes(...)` 判断入口。
2. 子页 `onShow` 用 `requireFeature('key')`；超管页可用 `requireSuper()`。
3. 无权限时：不渲染入口 + 直达链接要 toast「当前账号无权访问该功能」并返回。
4. 权限只决定可见性，数据边界仍由后端 `scopeCustomersForUser` / `scopeLeadsForUser` 等守卫。

## 4 设计系统

### 4.1 视觉基调
静奢东方疗愈：米灰底 `#F2F4F2` / 纯白卡 / 墨绿主色 `#2E7D5B`（深 `#1C6047`，墨 `#16201C`）/ 少量香槟金 `#C19A4B`。
数字用 tabular-nums；卡片圆角 28rpx；阴影极浅双层（`$shadow-card`）。

### 4.2 令牌
`src/styles/tokens.scss`：SCSS 变量 + Wot UI 主题 CSS 变量（`--wot-color-theme` 等）。
**页面禁止硬编码色值**，一律用 `$brand-500` / `$ink-500` 等或 CSS 变量。

### 4.3 组件（easycom：`^ym-(.*)` → `@/components/ym-$1/ym-$1.vue`）
| 组件 | 用途 | 关键 props |
|---|---|---|
| `ym-hero` | tab 页深色品牌头 | eyebrow / title / subtitle / compact / 插槽 badge、default |
| `ym-stat-card` | 指标卡 | label / value / unit / hint / trend / trendTone / tone(light·dark·brand·gold·plain) |
| `ym-chart` | 折线/柱状/环形 | type / data / labels / height(rpx) / color / color2 / colors / unit / precision / centerLabel |
| `ym-section` | 区块容器 | title / desc / actionText / bare，事件 `action` |
| `ym-badge` | 状态标签 | text / tone(brand·gold·warn·danger·info·muted) / size / plain |
| `ym-empty` | 空态/失败态 | text / desc / actionText / icon / compact，事件 `action` |
| `ym-cell-row` | 信息行 | label / value / hint / arrow / divider / clickable，事件 `click` |
| `ym-avatar` | 头像 | name / src / size(rpx) / tone |

Wot UI 组件直接用：`wd-button` `wd-cell` `wd-cell-group` `wd-input` `wd-textarea` `wd-search` `wd-tabs` `wd-tab` `wd-popup` `wd-toast` `wd-icon` `wd-switch` `wd-picker` `wd-segmented` `wd-tag` `wd-loadmore` `wd-skeleton` `wd-action-sheet` `wd-status-tip` `wd-progress` `wd-checkbox`。
**不要用**（太重）：`wd-calendar` `wd-img-cropper` `wd-upload` `wd-table` `wd-slide-verify` `wd-signature` `wd-watermark` `wd-datetime-picker`。

### 4.4 布局硬规则
- 卡片外边距统一 `20rpx 24rpx`（用 `ym-section` / `ym-card` 自带）。
- 触控目标 ≥ 88rpx 高；列表行 `min-height: 96rpx`。
- 分页列表用 `onReachBottom` 加载下一页，底部 `wd-loadmore`；空列表用 `ym-empty`。
- 页面必须处理三态：加载（`wd-skeleton` 或骨架卡）、空、错误（`ym-empty` + 重试）。
- 375px 宽下不允许横向溢出（长文本 `ym-ellipsis` 或 `line-clamp`）。

## 5 页面规格

### 5.1 工作台首页（dashboard）
数据源：
- `GET /today/summary` → `{newLeads, pendingFollowup, expiringMembers, riskCount, pendingApprovals, todayBookings:{绿地店,东部店}, trialBookings:{...}, todayKinds, scopeLabel, snapshotTime, snapshotAvailable}`
- `GET /analytics/summary` → `{totalCustomers,totalMembers,unassigned,assignRate,closureRate,renewalTasks,renewalRate,taskRate,doneTasks,totalTasks,revenueMix}`
- `GET /analytics/trends?start&end` → `{daily:[{date, '绿地店':{leads,booked,experienced,deals,classes,amount,redeem,...}, '东部店':{...}}], summary:{leadCount,bookingCount,visitCount,dealCount,dealAmount,dealRate,leadToVisitRate,...}, visit30, activeCustomers, attendanceSummary:{m1,m2,m3}, period}`
- `GET /today/todo` → 分组数组或 `{group:items}`（沿用现有 `fetchTodayTodo`）
- `GET /post-class-reviews/pending-count` → 角标

布局（自上而下）：
1. `ym-hero`：eyebrow=门店，title=问候 + 姓名，subtitle=角色 · 数据截至；右侧 badge 放「首页」入口。
2. 四张指标卡 2×2：今日预约（两店合计）/ 新客资 / 待跟进 / 卡项临期；riskCount 与 pendingApprovals 作为 hint/副行。
3. 「30 天经营走势」：`ym-chart type=line`，双序列切换（留资 / 到店 / 成交）用 `wd-segmented`。
4. 「转化漏斗」：留资→到店→成交，用三段横条（CSS，不用图表库），带转化率。
5. 「今日待办」摘要：前 3 条（标题 + 标签），点击进 `pages/todo/todo`。
6. 「快捷入口」：`visibleFeatures(roles)` 取 crm/biz/ai 入口，最多 8 个宫格；角标：课后分析待处理数。
7. 下拉刷新；`onShow` 刷新；错误态整页 `ym-empty` + 重试。

> 新媒体（R_MEDIA）没有会员管理：指标卡自动少一项，宫格按权限收敛，不显示空块。

### 5.3 新客培养
`GET /new-members/cultivation?start&end&venue&name&cardType`
→ `{records:[{id,name,phoneTail,venue,enrolledAt,enrolledDays,consultant,mainCard,categories:{private:{signed,booked,no_show,target},small:{...},group:{...}},totalSigned,primaryKind,primaryProgress:{signed,target},themes:string[],health:'idle'|'cultivating'|'cultured'}], summary:{total,private,small,group,idle,cultivating,cultured}, targets:{private,small,group}, range:{start,end}, syncTime}`
- 顶部 4 个统计：新客总数 / 待激活 / 养成中 / 已养成。
- 筛选：搜索姓名（`wd-search`）、课型 segmented（全部/私教/小班/团课 → cardType）、门店 picker（仅 SUPER/MANAGER 显示）。
- 卡片：姓名 + 门店 + 入会天数 + 主推课型进度条（`wd-progress`）+ 健康度 badge + 主题 chips；点击进 `pages/members/detail?id=`.

→ `PageResult<MiniappCustomer>`（字段见 `src/types/index.ts`）

### 5.5 AI 助手 hub
- 两张主卡：营销工具（ALL）/ 谈单工具（MGMT，无权限不渲染）。
- 「最近生成」：本地缓存最近 3 条文案摘要（`uni.getStorageSync('yimai-ai-recent')`），点击进营销工具。
- 说明文案：AI 生成内容需人工审核后发布。

### 5.6 营销工具
两段式（`wd-segmented` 朋友圈 / 小红书）：
- 表单：主题（textarea）、人设（picker，来自 `GET /my/profile` 的 `profile.persona.role` 兜底默认）、语气（自然真实/专业干货/轻松幽默/温暖治愈/元气满满）、长度（短/中/长）、门店/课程卖点（可选）。
- 生成：`POST /ai/chat`，body `{messages:[{role:'system',content:PROMPT},{role:'user',content:userPrompt}], temperature:0.8, maxTokens:1200, featureType:'marketing_moments'|'marketing_xhs'}` → 返回 `{content, prompt, usage...}`（后端 `ok()` 包裹，`http` 已解包；实际字段以 `content` 为准，兼容 `data.content`）。
- 结果卡：3 条候选（按 `\n---\n` 或编号切分；切不出就整段一条）+ 复制 + 重新生成 + 收藏。
- 历史：`GET /marketing/history?platform=朋友圈|小红书`；收藏：`GET/POST/DELETE /marketing/favorites?platform=...`（写入体 `{platform,title,content,reply,coverText,tags}`）。
- 复制用 `copyText()`。
- 权限 `requireFeature('marketing')`。

### 5.7 谈单工具（MGMT）
1. 客户分享页状态：`GET /shares/current?type=sales` → `{enabled, token, code, views, needsRepublish, viewingOther, ownerName, ownerUserId}`
   - 已开启：显示访问量 + 「复制客户链接」`${VITE_SHARE_BASE||https://oa.nbyimai.com}/#/s/{code}`（web 端 hash 路由，实测 `buildSalesShareHash()` 输出 `#/s/{code}`）+ 「停用分享」`POST /shares/disable {type:'sales'}`。
   - 未开启/需重发：提示「请在电脑端营销工具重新开启分享」。
2. 谈单话术生成：场景 segmented（首次咨询 / 价格异议 / 邀约到店 / 续费挽回 / 沉睡唤醒）+ 客户类型（新客/会员/VIP）+ 备注 textarea → `POST /ai/chat` `featureType:'chat'`，输出「开场 / 价值 / 收尾」三段 + 复制。
3. 常见异议速查（本地静态 6 条，可折叠）。
- 权限 `requireFeature('sales')`。

## 6 后端：微信订阅消息（模板通知）

### 6.1 表
`wx_subscriptions`：`id, user_id, template_key, remain(int), total_accepted(int), last_accepted_at, last_sent_at, timestamps`，唯一键 `(user_id, template_key)`。
`wx_subscription_logs`：`id, user_id, template_key, status(sent|skipped|failed), errcode, errmsg, payload(json), timestamps`。

### 6.2 服务 `App\Services\WeChatSubscribeMessage`
- `accessToken()`：`/cgi-bin/token`，Cache 7000s，失败记 warning 返回 null。
- `catalog()`：读 `config('services.wechat.templates')`，返回 key/title/desc/templateId/enabled/fields。
- `send(User $u, string $key, array $data)`：未配置/未绑定/remain<=0 → skipped 日志；成功 remain-1 并写 last_sent_at。
- 错误码：43101（用户拒收）→ 归零 remain 并提示重新授权；40037（template_id 不对）→ error 日志。

### 6.3 接口（`auth:sanctum`）
- `GET /wx/subscriptions` → `ok({configured, bound, templates:[{key,title,desc,enabled,templateId,accepted,remain,lastAcceptedAt,fields}], updatedAt})`
- `POST /wx/subscriptions` `{accepts?:string[], denies?:string[]}` → `ok({templates:[...]})`（accepts 每个 key remain+1，`total_accepted` 累加）
- `POST /wx/subscriptions/test` `{key}` → `ok({sent,message})`；未配置/未绑定 → 422 可读文案。

### 6.4 触发
- 留资：`LeadController::store/update` 中 `service_teacher` 变为非空且与旧值不同 → 通知该老师（`leadAssigned`）。
- 会员：`CustomerController` 归属变更（`owner` / `consultant_user_id`）→ 通知新归属人（`memberAssigned`）。
- 发送放 `defer(fn () => ...)`（Laravel 11+），失败只写日志，不影响主请求。

### 6.5 配置
`config/services.php` → `wechat.templates`：
```php
'leadAssigned' => ['title'=>'新客资分配提醒','desc'=>'有新的客资分配到您名下时通知','template_id'=>env('WECHAT_TPL_LEAD_ASSIGNED',''),'fields'=>[...]],
'memberAssigned' => [...env('WECHAT_TPL_MEMBER_ASSIGNED')...],
'todoReminder' => [...env('WECHAT_TPL_TODO')...],
```
`.env.example` 补三个键；未配置时接口 `configured:false`，页面显示「待管理员配置模板」，不报错。

## 8 验收标准

1. `npx vue-tsc --noEmit` 0 错误。
2. `npx uni build -p mp-weixin` DONE，主包 ≤ 1.2MB。
3. `app.json` 含全部 22 页；tabBar 4 项带图标。
4. 每个 tab 页在未登录时跳登录；无权限子页能 toast + 返回。
