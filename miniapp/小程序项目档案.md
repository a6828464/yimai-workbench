**HTTP 契约（`src/utils/http.ts`，R4 闸门）**：
1. `wx.request` 任何 statusCode 都进 success → 必须自判 2xx，否则「密码错也显示登录成功但白屏」
2. 三形态 unwrap：`{code,message}` / `{ok:false}` / `{errno,emsg}`
3. 401 → 清 token → `reLaunch` 登录页（3s 防抖）；403 归一化 toast
4. 运行时证据：`node verify/http-gate.test.mjs`（15 条断言，非文档声称）

### 5.1 备案结论（2026-11-04 核实官方 FAQ）

**备案不绑代码。** 微信《小程序备案常见问答》十五·1 明确：需要变更备案的是「小程序名称、小程序服务内容、小程序管理员信息、主体证件信息、主体负责人信息」——**代码与版本不在其中**。

| 动作 | 是否触发备案变更 |
|---|---|
| 换代码 / 换技术栈 / 重写页面 | ❌ 不需要 |
| 新增或删除功能但服务类目不变 | ❌ 不需要 |
| 改小程序名称 | ✅ 需要（7 日内） |
| 服务内容/类目实质变化 | ✅ 需要（走「变更」，非注销） |
| 主体名称变但信用代码不变 | ✅ 变更即可 |
| 主体信用代码变了 | ✅ 先注销再重新备案 |

变更备案期间**不影响小程序正常使用**；平台初审 1–2 工作日 + 管局 1–20 工作日。
依据：`https://developers.weixin.qq.com/miniprogram/product/record/record_faq`（以官方最新规则为准）
